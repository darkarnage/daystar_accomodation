# Design

This folder holds the CampusNest designs created with **Google Stitch**.

- Put Stitch exports (screenshots, HTML/CSS exports, assets) in the matching subfolder:
  `brand/`, `home/`, `browse/`, `property-details/`, `authentication/`, `submission/`,
  `admin/`, `supporting-pages/`, `ui-states/` (empty, loading, error states).
- Keep the original exports unchanged so there is always a reference to compare against.
  Name files clearly, e.g. `browse-desktop-v1.png`.
- These designs will be used later as the reference when implementing the frontend in `public/`.
- Do not generate or invent designs here. Only add real exports from Stitch.
